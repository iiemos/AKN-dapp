## Network：注册与网体展示


| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `register(address referrer)` | `referrer`：已注册上级地址 | 当前钱包绑定推荐人，绑定后不可更改；上级不能是自己。成功注册后才能预售入金。已注册用户用相同推荐人重复调用不会创建新关系。 |
| `isRegistered(address member) → bool` | `member`：要查询的钱包地址 | 判断用户是否已注册。 |
| `referrerOf(address member) → address` | `member`：用户地址 | 查询直属推荐人；Top 会员返回零地址。 |
| `topMember() → address` | 无 | 查询网体 Top 会员地址，可作为首批用户的推荐人。 |
| `directCount(address member) → uint256` | `member`：用户地址 | 查询直属注册人数。 |
| `directMembers(address member, uint256 offset, uint256 limit) → address[]` | `offset`：从 0 开始的偏移；`limit`：本页数量，最大 100 | 分页查询直属成员地址；超过末尾返回空数组。 |
| `uplines(address member, uint256 maxDepth) → address[]` | `member`：用户地址；`maxDepth`：最多查询层数，最大 100 | 从直属上级开始，依次返回上级链。 |
| `isActive(address member) → bool` | `member`：用户地址 | 查询网体活动状态。**已注册不等于活跃**；一期预售入金不会自动把此值设为 `true`。 |


## Presale：入金与订单


金额均为 **18 位精度**的 USDT 基础单位：`100 USDT = 100 × 10^18`。前端传 `uint256` 整数，不要传浮点数。


| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `USDT() → address` | 无 | 查询当前预售绑定的代币地址；交易前应以此地址为准。 |
| `startsAt() → uint64` | 无 | 预售开始的 Unix 秒级时间戳；此前不能入金。 |
| `closed() → bool` | 无 | `true` 表示预售已关闭，不能继续入金。 |
| `lastInvestmentOf(address member) → uint256` | `member`：用户地址 | 查询用户上一笔入金金额；下一笔不得低于该值。 |
| `invest(uint256 amount, uint8 packageId) → uint256 orderId` | `amount`：100～10,000 USDT，且必须为整数 USDT；`packageId`：1、2、3 或 4 | 当前钱包入金。需先在 Network 注册，并先向 Presale 代理授权足额 USDT。交易成功后获得新订单；资金直接转到当期收款地址，而非留在 Presale 合约。 |
| `memberOrderCount(address member) → uint256` | `member`：用户地址 | 查询用户订单总数。 |
| `memberOrderIds(address member, uint256 offset, uint256 limit) → uint256[]` | `member`：用户地址；`offset`：从 0 开始；`limit`：最大 100 | 分页查询指定用户的订单 ID，适合公开用户主页。 |
| `getOrderDetail(uint256 orderId) → OrderDetail` | `orderId`：订单 ID | 查询订单本金、套餐、推荐人、收款地址、时间及累计收益，字段见下文。不存在的 ID 返回全零结构。 |
| `getMemberOrders(uint256 page) → (uint256[] orderIds, OrderDetail[] orderList)` | `page`：从 **1** 开始，每页最多 100 笔 | 一次查询**调用者 `msg.sender`**的订单 ID 和详情。查询别人的订单时使用 `memberOrderIds` + `getOrderDetail`。 |
| `totalInvestmentOf(address member) → uint256` | `member`：用户地址 | 查询该用户预售累计入金本金。 |
| `formalLaunchAt() → uint64` | 无 | 正式系统启动时间；`0` 表示尚未启动。 |


`OrderDetail` 中前端常用字段：`orderId`、`member`、`referrer`、`principal`、`createdAt`、`packageId`、`receiver`、`accruedDays`、`presaleReward`、`formalReward`、`accruedReward`、`nextAccrualAt`、`presaleClosed`、`formalSystemActive`。金额字段均为 18 位精度；时间字段为 Unix 秒。`accruedReward` 是**计算出的累计收益**，不是当前可领取余额；一期没有领取入口。


## USDT：入金前两步


| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `balanceOf(address account) → uint256` | `account`：用户地址 | 检查用户余额是否足够。 |
| `allowance(address owner, address spender) → uint256` | `owner`：用户地址；`spender`：Presale **代理地址** | 检查现有授权额是否足够。 |
| `approve(address spender, uint256 amount) → bool` | `spender`：Presale **代理地址**；`amount`：至少覆盖本次入金 | 授权后等待交易确认，再调用 `invest`。 |


客户端顺序：连接 chainId `97` → 检查/调用 `Network.register` → 检查 `Presale.startsAt`、`closed` 与 USDT 余额/授权 → 必要时 `approve` → `Presale.invest` → 按订单 ID 查询详情。
